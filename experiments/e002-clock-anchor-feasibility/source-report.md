# T-006: offline timestamp-candidate coverage

The trade-assisted diagnostic assigns point timestamp candidates to 91,860 of the same 91,868 BTC book changes used by T-001, versus 90,083 for the initial status-only join. This adds 1,777 candidates and increases coverage from 98.0570% to 99.9913%. Eight update events remain unmatched. One 182.854823 ms time inversion remains and is preserved in the output. This is an **offline data diagnostic, not a market performance result or a certified causal replay**.

## Inputs and method

No new data were downloaded. The inputs are the frozen T-001 December 1, 2025 hour-0 members. The denominator is the first 200,000 original interleaved book-diff lines, containing 91,868 BTC events; it is not the entire hour's BTC book events. Candidate lookup reads the full acquired status hour and the full 500,408-line trade hour, including 101,223 BTC executions.

The method is a scoped implementation informed by `dec2025_reconstruction/decode_timing_hour.py` at [public-trader-identity commit 7fd7616](https://github.com/daojingzhai/public-trader-identity/tree/7fd7616b8a3af5193ff9efe9d5b27e4bae7c3135/dec2025_reconstruction). New events match open statuses. Removals prefer zero-size non-open statuses and otherwise use terminal statuses. Updates match both trade legs by order ID and an exact decimal quantity reduction. Ordinal matching is used only when the observed book-update and trade multiplicities for the same order and size agree; otherwise matching retains an interval. Missing exact-size matches remain missing rather than falling back to an arbitrary trade time.

```python
fill = units(update["origSz"]) - units(update["newSz"])
candidate, source = update_candidate(trades[(oid, fill)], ordinal, book_count)
```

Decimal arithmetic uses integer units of 10^-8, avoiding source float32 size keys. Point candidates remain matching outcomes, not independently validated timestamps. The full-hour join can use later rows, so it cannot demonstrate when information was available to an online trader.
